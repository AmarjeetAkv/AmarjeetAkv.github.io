# amarjeetakv.github.io

Personal portfolio of Amarjeet Kumar Verma, QA Automation Engineer. Live at https://amarjeetakv.github.io/

A single static page served by GitHub Pages from the root of `main`. There's no build step, no framework and no third-party scripts, fonts or analytics.

```
index.html                              page content, styles and a small script (theme, mobile menu, copy email)
assets/Amarjeet_Kumar_Verma_Resume.pdf  public résumé (no phone number)
assets/profile.jpg                      profile photo
assets/favicon.svg, apple-touch-icon.png
assets/og-image.png                     1200×630 link preview for LinkedIn and other sites
```

To update the résumé, replace `assets/Amarjeet_Kumar_Verma_Resume.pdf` and keep the same file name, so the download links keep working.
