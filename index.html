I'm a Senior QA Engineer at Northern Block with 8+ years of testing API, web, mobile and AI-driven applications. My core is Python test automation with Behave (BDD), Playwright, Selenium and Appium.

For the last few years I've worked deep in decentralised identity, testing ACA-Py, AnonCreds, JSON-LD and W3C verifiable-credential issuer, holder and verifier workflows end to end, from cloud agents to mobile wallets.

I build CI-integrated suites on GitHub Actions and Jenkins with Allure and Confluence reporting, and I contribute to OWL Akrida, an open-source Locust-based framework for load testing ACA-Py and DIDComm agents.

In Agile teams I own quality across several projects running in parallel.
